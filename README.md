# AI Portfolio & Intelligent Agent Workspace

A production-ready portfolio and intelligent agent ecosystem designed to bridge the gap between autonomous robotics, machine learning research, and clean web interfaces.

## What It Does & For Whom
* **For Employers & Reviewers:** Provides verified, reproducible evidence of full-stack engineering, rigorous ML model validation, and responsive UI/UX development.
* **For Users:** Acts as an interactive professional showcase and automated content-analysis decision-support assistant.

## Setup Steps (For a Stranger to Reproduce)
1. **Clone the repository:**
   ```bash
   git clone https://github.com/JustSuffer/assignmentportfolio.git
   cd assignmentportfolio
   ```

2. **Install dependencies & run locally:**
   ```bash
   cd portfolio
   npm install
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## Tech Stack
* **Frontend:** React 19, Vite, Modular CSS (Clean Technical Minimal Aesthetic)
* **Deployment:** Netlify (`netlify.toml` SPA rewrite rules configured)
* **Architecture:** SPA architecture with interactive case studies, live AI skill benchmark lab, and responsive telemetry controls.
